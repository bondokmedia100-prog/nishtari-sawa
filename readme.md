# نشتري سوا

## إصدار الخادم 15

- API: https://nishtari-sawa.onrender.com/
- واجهة الويب: https://nishtari-sawa-preview.pages.bu.app/
- الحزمة `nishtari-sawa-project-v15.zip` تتضمن ملفات الخادم والترحيلات حتى `013_manual_transfers.sql`.
- قاعدة بيانات البائعين هي مصدر العروض والأسعار والكميات؛ لا تُعرض بيانات بذور تجريبية افتراضيًا.

## التحويل اليدوي

- يقبل الطلب فودافون كاش أو إنستا باي، ويعرض رقم التحويل في صفحة الطلب.
- يرفع المشتري صورة الإيصال؛ لا يُعتبر الدفع مؤكدًا حتى تراجعه الإدارة وتعتمده.
- لا يوجد تحصيل إلكتروني تلقائي أو ضمان لصحة التحويل من النظام.

## النشر والبيانات

- خدمة Render تبني `dockerfile` من جذر المستودع، ويطبّق الخادم الترحيلات المسجلة عند بدء التشغيل.
- إعداد Free الحالي للتجربة فقط؛ قد تتوقف الخدمة مع الخمول، وقاعدة البيانات المجانية لا توفر استعادة احتياطية قابلة للاسترجاع وقد تنتهي صلاحيتها.
- لا تستخدم بيانات لا يمكن خسارتها أو تشغيلًا تجاريًا على هذه الخطة.

## الاختبارات

- `node --test`: 45 اختبارًا ناجحًا.
- الترحيلات لم تُختبر على قاعدة PostgreSQL الإنتاجية قبل النشر.
